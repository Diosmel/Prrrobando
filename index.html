● Repositorio preparado para IA open source

Tu base para crear una IA personalizada

Este repositorio fue limpiado como proyecto inicial para adaptar una inteligencia artificial de código abierto. La opción recomendada es Open WebUI: una interfaz tipo ChatGPT que puedes conectar con Ollama, OpenAI-compatible APIs y modelos locales.

git clone https://github.com/open-webui/open-webui.git
Open WebUI Base recomendada para crear tu propio chat IA editable y self-hosted.
Ollama Permite correr modelos locales como Llama, Mistral, Qwen o DeepSeek.
Personalizable Cambia logo, colores, flujo de login, herramientas y comportamiento del asistente.
