# Prueba Web Diosmel

Página web de prueba creada con HTML, CSS y JavaScript en un solo archivo.

## Archivo principal

- `index.html`

## Cómo ver la página publicada

1. Entra al repositorio en GitHub.
2. Ve a **Settings**.
3. Entra a **Pages**.
4. En **Build and deployment**, selecciona:
   - **Source:** Deploy from a branch
   - **Branch:** main
   - **Folder:** /root
5. Guarda los cambios.

Cuando GitHub Pages termine de publicar, la web debería verse aquí:

https://diosmel.github.io/Prrrobando/

Si no abre al instante, espera unos minutos y refresca la página.
